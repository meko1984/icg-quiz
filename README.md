# 感染制御クイズ

感染制御認定士講座の試験対策用4択クイズ。第1回・第2回の精査済み188問を収録し、問題と選択肢をセッションごとにランダム化する。

## 主な機能

- タイトル画面から「サクッとまとめ」「解いて確認」「開発者メッセージ」を選択
- タイトル画面でキーワード検索し、まとめページと関連クイズをまとめて表示
- まとめの章選択と「5moments」「抗菌薬の違い」「グラム染色 × 菌の形」の基礎ページ（出典付き）
- 開発者メッセージと package.json に連動したバージョン表示（メッセージ本文は案）
- 第1回、第2回、全範囲から出題
- 10問、20問、30問、全問を選択
- 回答直後の正誤判定と解説
- 間違えた問題だけを復習
- 成績と復習リストをブラウザ内に保存
- スマートフォン表示とPWAに対応

成績は利用中のブラウザ内だけに保存され、サーバーへ送信されない。

トップは `/`、既存クイズは `/quiz/`、まとめ一覧は `/summary/`、開発者メッセージは `/developer/`。クイズの保存キーと記録形式は従来と同じ。同一オリジンでの更新では既存記録を読み込める。

## 注意

このアプリは学習用であり、実際の医療判断や施設手順を代替しない。実務では所属施設の最新手順、製品表示、感染対策担当者の指示を優先する。
