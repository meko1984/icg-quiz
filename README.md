# 感染制御クイズ

感染制御認定士講座の試験対策用4択クイズ。第1回・第2回の精査済み188問を収録し、問題と選択肢をセッションごとにランダム化する。

## 主な機能

- タイトル画面から「解いて確認」「サクッとまとめ」「開発者メッセージ」を選択
- タイトル画面でキーワード検索し、まとめページと関連クイズをまとめて表示
- 第1回・第2回に分けた12のまとめページ。曝露後対応、洗浄、肝炎・HIV、感染成立の6要素、菌名の由来、Miller & Jones分類、抗菌薬耐性などを図解（出典付き）
- 開発者メッセージと package.json に連動したバージョン表示（メッセージ本文は案）
- 第1回、第2回、全範囲から出題
- 10問、20問、30問、全問を選択
- 回答直後の正誤判定と解説。回答後は問題数と次へボタンを画面下に固定し、選択肢は開いて見直せる
- 間違えた問題だけを復習
- 成績と復習リストをブラウザ内に保存
- スマートフォン表示とPWAに対応

成績は利用中のブラウザ内だけに保存され、サーバーへ送信されない。

トップは `/`、既存クイズは `/quiz/`、まとめ一覧は `/summary/`、開発者メッセージは `/developer/`。クイズの保存キーと記録形式は従来と同じ。同一オリジンでの更新では既存記録を読み込める。

## 注意

このアプリは学習用であり、実際の医療判断や施設手順を代替しない。実務では所属施設の最新手順、製品表示、感染対策担当者の指示を優先する。

## 内容と参照資料の扱い

タイトル検索と章一覧は `app/lib/study-topics.ts` を共有する。問題の関連リンクは `app/lib/related-study.ts` で管理する。新しいまとめページは各ページ末尾に出典と確認日を記載し、代表値と最新の報告の条件を区別する。

感染成立の6要素は第1回資料の分類（病原体・病原性・病原体の量・伝播経路・侵入門戸・感受性のある宿主）。感染源・排出門戸を含む別の6分類と混同しない。問題ID・正答・選択肢は2026年9月9日の解説更新で維持している。
